agent-cost-proxy

It listens on 127.0.0.1 only and refuses browser requests. Your agent's own key header is passed through. If the agent sends none, the proxy uses the upstream's usual environment variable. Keys, prompts and responses are never written or printed. Then run npx -y github:xbtMelchizedek/agent-cost-proxy report.

How cost is worked out

  1. Reported by the upstream: OpenRouter returns usage.cost in credits, where 1 credit is $1. This is the real charge.
  2. Your price: --price 3,15 sets USD per 1M input and output tokens, times the tokens the response reports.
  3. The venue's list price in justweight, for that exact model at that venue.
  4. Estimate: OpenRouter's list price for the same model, flagged estimate, because the maker's own price may differ. Cached input is priced at the full input rate, so with caching this is an upper bound.

If none of these apply, the call is recorded as unpriced, never as $0. Cheapest is the lowest USD list price justweight has for the same model and the same token counts. It is not a quality, latency or privacy match. With caps on, each call holds an upper bound before it goes out. Calls over a cap get a 403 and never reach the provider.
